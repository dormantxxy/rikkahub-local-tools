RikkaHub 3.1.1 增强版

本次更新：

【性能】
- 换回轻量 Markdown 引擎：3.x 的新引擎对每条消息都要走 Markdown → HTML → Jsoup → DOM，
  比 2.5.1 重得多。现在纯文本消息直接渲染 AST，只有内嵌 HTML 的消息才走重型路径，
  长对话与流式输出明显更顺。
- 头像动画按需运行：非加载态不再常驻旋转动画。
- 渐变背景动画接入生命周期：切到后台自动暂停，不再空转发热。

【修复】
- 修复 build.gradle 丢失 versionName，导致 APK 版本名显示为 null。

【保留的功能】
- LaTeX 公式渲染与开关、行内公式自动换行拆分
- 搜索引用角标、引用文本高亮开关
- 工作区图片路径解析（Markdown 里的 rootfs 绝对路径可正常显示）
- 代码高亮、Mermaid 图、表格、差异视图

历史版本功能（上一版）：
- 扩展商店在线模式：默认 16 个精选扩展，搜索覆盖 3000+ Termux 软件包
- Termux .deb 安装支持（ar + data.tar.xz 解压、依赖自动安装）
- 本地工具：env_info、pkg_search、pkg_install、tap、swipe、input_text、ui_dump、screenshot、logcat、应用管理
- 工具链工作区：无需 rootfs，用已装扩展的聚合环境执行命令
- 工作区工具隔离：绑定 Rootfs/SSH 时设备级工具不再暴露，命令走 workspace_shell
- 设备 Shell 审批开关（默认关闭）
